# Website Agroforestri Tj. Anom

Website laporan lapangan dengan tema hutan/agroforestri.

## Isi
- Beranda hero menggunakan foto lapangan
- Pendahuluan
- Tempat & metode penelitian
- Daftar 18 jenis tanaman
- Jenis hewan/peternakan
- Galeri 10 foto asli
- Peta Tj. Anom
- Identitas penyusun
- Responsive HP/laptop
- Lightbox foto dan animasi

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di Chrome/Edge untuk melihat website.
3. Untuk GitHub Pages, upload `index.html`, `style.css`, `script.js`, dan folder `images` ke repository.
4. Aktifkan Settings > Pages > Deploy from branch, pilih branch `main` dan folder `/root`.

Catatan: peta menggunakan wilayah umum Tj. Anom. Jika kamu punya koordinat/titik GPS lahan, bagian peta bisa dibuat lebih presisi.
